## What I'm exploring

- **Applied AI and software development:** turning ideas into applications and learning how their components fit together.
- **Machine learning and NLP:** designing models and evaluating their behaviour, from data preparation to predictions.
- **Security and privacy:** understanding how AI applications handle data and how to make them more reliable and secure.

## Learning through projects and work

Alongside my studies, I work in showroom reception and administrative support. Seeing everyday customer requests and appointment workflows has inspired me to explore how software and AI could support this kind of work.

My personal projects are also a way to learn beyond coursework, especially about databases, API integrations and web application development. I use AI-assisted development tools while working to understand the code and test what I build.

## Selected academic projects

- [Spotify Genre Classification](https://github.com/den-bene/Spotify-Genre-Classification) — Classification of 10,000 tracks across ten genres, comparing linear models, KNN and Random Forest through cross-validation, with a focus on regularization and error analysis.
- [Multi-label News Classification](https://github.com/den-bene/Multilabel-News-Classification) — A TensorFlow/Keras network combining BiLSTM text representations, Bag-of-Words features and publication metadata to classify news into 18 categories. Includes configuration comparison and validation-based threshold selection.
